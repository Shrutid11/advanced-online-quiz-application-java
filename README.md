# 🎯 Advanced Online Quiz Application

An interactive console-based Online Quiz Application developed using **Java** implementing **OOPs concepts**, **collections framework**, **file handling**, **random question generation**, **leaderboard system**, and **score analysis**.

This project demonstrates strong Core Java fundamentals and problem-solving skills through a menu-driven quiz platform.

---

# 🚀 Features

✅ User Login System  
✅ Multiple Choice Questions  
✅ Random Question Generation  
✅ Score Calculation  
✅ Percentage & Grade System  
✅ Leaderboard System  
✅ File Handling using `scores.txt`  
✅ Timer Simulation  
✅ Result Analysis  
✅ Replay Capability  
✅ Exception Handling  
✅ Interactive Console UI
